My Music Studio v2

使い方
1. ZIPを解凍する
2. index.html、app.js、sw.js、manifest.webmanifest、icon.svg の5ファイルをGitHubリポジトリのルートにアップロード
3. Settings > Pages > Deploy from a branch > main / root で公開
4. iPhoneのSafariで公開URLを開き、共有 > ホーム画面に追加

機能
- 曲ごとのプロジェクト
- アイデアのマイク録音・複数音声ファイル取り込み・メモ
- デモ/完成版のバージョン管理、変更点メモ
- 2音源のA/B聴き比べ（再生位置同期、区間ループ、比較メモ）
- 歌詞、コード進行、キー、BPM
- 世界観メモ、参考画像アップロード
- 制作チェックリスト
- プロジェクト単位のJSONバックアップ・復元
- iPhoneのダブルタップ拡大抑制、16px入力欄

注意
- データはブラウザ内のIndexedDBに保存されます。端末間同期はありません。
- ブラウザのデータ削除や容量不足でデータが消えることがあります。定期的にバックアップしてください。
- 音声ファイルが大きいとバックアップJSONも非常に大きくなります。
- 録音にはHTTPS（GitHub Pagesで対応）とマイク権限が必要です。
- 対応する音声コーデックは端末・ブラウザに依存します。
- A/B比較は「同じ秒数」に切り替えます。曲頭の無音やテンポが異なる音源を自動整列するものではありません。
- ループ開始・終了は秒数で指定します。
